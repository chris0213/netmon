# 网哨 NetMon · 安装说明（发给同事用）

网哨是一个 macOS 网络健康监控小工具：常驻后台每 30 秒探测一次网络，出问题时生成一份可离线打开的 HTML 报告。全程数据只存在你自己电脑上，不上传、不外发。

---

## 一、安装（3 步）

1. 双击 `NetMon-1.1.0.dmg` 打开。
2. 把 **网哨 NetMon** 拖进 **Applications** 文件夹。
3. 从「启动台」或 Applications 双击打开。

### 如果双击提示"无法打开，来自身份不明的开发者"

这是 macOS 的默认安全策略，不是病毒。本应用未购买 Apple 开发者签名，所以系统首次会拦一下。两种办法任选其一：

- **办法 A（推荐，最简单）**：在 Applications 里**按住 Control 点击**（或右键）**网哨 NetMon** → 选 **打开** → 弹窗里再点 **打开**。之后就能正常双击了。
- **办法 B**：首次打开后，去 **系统设置 → 隐私与安全性**，找到"已阻止使用网哨 NetMon"的提示，点 **仍要打开**。

## 二、运行环境

**不需要安装任何东西。**

网哨自带 Python 运行时和图形库（Tcl/Tk 9），不依赖你电脑上有没有装过 Python。安装包因此有 23MB 左右——这是为了换掉两个坑：对方没装 Python 就打不开、系统自带的旧版 Python 打开是白屏。

| 项目 | 要求 |
| --- | --- |
| macOS 版本 | 11.0（Big Sur）及以上 |
| 芯片 | Apple 芯片（M1 / M2 / M3 / M4） |
| Python | 不需要，已内嵌在应用里 |
| 第三方库 | 不需要，只用 Python 标准库 |

> **Intel 芯片的 Mac 跑不了这个包。** 内嵌的运行时是 arm64 架构，需要 Intel 版本请找 IT 要专门构建的包。

如果打开后仍然是白屏，把 `~/Library/Application Support/NetMon/gui-launch.log` 发给 IT——里面记录了实际使用的解释器路径，能直接定位问题。

## 三、怎么用

**默认中文界面**。需要英文时，用文本编辑器打开 `~/Library/Application Support/NetMon/config.json`，把开头的 `"language": "zh"` 改成 `"en"`，保存后完全退出应用再打开，界面和报告都会变成英文。

打开后是一个浅色控制台，底部有 6 个按钮：

| 按钮 | 作用 |
| --- | --- |
| 启动监控 | 开始后台采集（每 30 秒一轮），关掉窗口也不会停 |
| 停止监控 | 结束后台采集 |
| 生成报告 | 汇总当天数据，生成一份 HTML 报告 |
| 报告文件夹 | 打开报告所在目录，可选任意一天的旧报告 |
| 立即自检 | 立刻采一轮，弹窗展示各层网络的实测数据 |
| 清除数据 | 把历史数据归档备份（先停监控才能点），可恢复 |

典型流程：**启动监控 → 用一段时间（或等故障复现）→ 生成报告 → 把报告发给 IT**。

## 四、隐私说明（重要）

- **数据只在你本机**：采集结果存在 `~/Library/Application Support/NetMon/`，报告就是普通 HTML 文件，不会自动发送给任何人。
- **报告已默认脱敏**：生成的报告会自动隐藏你的内网 IP、网关、设备 MAC 地址，只保留排障需要的公网目标和网络质量指标。因此可以放心转发。
- **如果你要把报告发给 IT 排障、需要保留真实内网地址**：编辑 `~/Library/Application Support/NetMon/config.json`，把 `privacy.redact_in_report` 改成 `false`，重新生成报告即可。这种情况下报告里会含真实内网信息，只在可信范围内转发。
- 本机保存的原始采样数据**始终是完整的**，脱敏只影响报告展示，不影响排障时看原始数据。

## 五、常见问题

**Q：关掉窗口，监控还在跑吗？**
在。要真正停止请点「停止监控」。关窗口时应用会问你要不要一起停。

**Q：报告里的"样本不足，仅供参考"是什么意思？**
采样点少于 10 个时，可用率数字仅供参考，不构成结论。让监控多跑一会儿再生成报告。

**Q：想彻底卸载？**
打开应用，点底栏右下角的 **卸载 NetMon…**，勾选要清理的内容（后台服务必选，数据和应用本体可选），确认后即可。被勾选的内容都会移进废纸篓，可以随时拖回来。如果只卸服务、不删数据，以后重装还能接着看历史报告。
